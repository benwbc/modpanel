To enable Live Game Data on the Lookup and Private Servers pages (currency, XP, private servers, etc.), set OPEN_CLOUD_API_KEY, UNIVERSE_ID, DATASTORE_NAME, and optionally DATASTORE_KEY_TEMPLATE (default {userId}) in your Render environment. See README.md.

Security

Every moderator has their own key (manage this from Data Management, admin only — revoke anyone anytime). The game server uses a separate GAME_API_KEY that the dashboard never sees. Repeated invalid keys from the same address are locked out for 5 minutes, and all API routes are rate-limited.

Data Management

Export panel data, and manage moderator access

Export data

Violations, actions, and moderator accounts are stored in JSON files on disk. Render's free tier disk isn't guaranteed to survive a redeploy — export regularly, or move to a hosted database (see README) once this data matters long-term.
